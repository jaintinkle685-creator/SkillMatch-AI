🧩 How the Algorithms Work — Visual Guide
Simple step-by-step explanation of the algorithms used by SkillMatch AI
CS-402 AOA
📋
1. Project Requirement Analysis

Compare every required project skill with every student's proficiency.

O(S × R)
S = students, R = required skills
🎯
2. Greedy Allocation

Pick the strongest available candidate for each important role/skill, then continue until all slots are filled.

O(N × K log N)
Fast baseline solution
🔗
3. Hungarian Matching

Build a student-to-role score matrix and find the best one-to-one assignment.

O(N³)
Bipartite assignment
🔄
4. Multi-Objective Optimization

Refine the initial teams using skill balance, role preference and experience balance until a high-quality solution is found.

O(G × P × N)
G = generations, P = population/solutions
Input Student Skills + Project Requirements → Analyze Project Requirements → Match Students to Roles → Optimize Teams → Output Explainable Teams

1. Multi-Objective Genetic Optimizer + 2-Opt

Primary Engine
Module: js/models/teamOptimizer.js

Iteratively refines student team permutations across Skill Balance, Role Preferences, and Peer Experience. Employs permutation chromosomes, tournament selection, and 2-opt pairwise hill-climbing swaps to escape local extrema.

Time: O(G·P·N log N)
Space: O(P·N)

2. Greedy Priority-Queue Allocator

Seed & Baseline
Module: js/models/teamOptimizer.js

Computes composite student-role fit scores and allocates top candidates greedily to bottleneck technical roles (e.g. AI Lead, Backend Architect), generating initial feasible seeds in sub-2ms time.

Time: O(N·K log N)
Space: O(N)

3. Bipartite Kuhn-Munkres Role Matcher

Role Assignment
Module: js/models/teamOptimizer.js

Solves optimal one-to-one assignment of students to specific defined roles within teams on an affinity-cost matrix, guaranteeing maximal role preference satisfaction via alternating augmenting paths.

Time: O(N³)
Space: O(N·M)
